### Creating Helpdesk Accounts:

As a manager generale, you can create helpdesk user accounts:

1. Login with manager generale credentials above
2. Navigate to **"Helpdesk Staff"** in the sidebar
3. Click **"Add Helpdesk Staff"**
4. Fill in:
   - Full Name
   - Email (will be used for login)
   - Password (minimum 6 characters)
   - Role (Technician or Admin - for categorization only)
5. Click **"Create Account"**

Helpdesk users will have limited access to:
- Equipment Management
- User Management  
- Interventions
